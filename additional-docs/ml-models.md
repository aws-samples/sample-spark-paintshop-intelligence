# ML Models

SPARK uses a three-model ensemble served from a single SageMaker Multi-Container Endpoint (`InferenceExecutionConfig: Direct`), allowing per-container invocation via `TargetContainerHostname`.

| Model | Algorithm | Purpose |
|-------|-----------|---------|
| Isolation Forest | sklearn 1.2 | Anomaly score per reading — detects instantaneous multivariate outliers |
| LSTM Autoencoder | PyTorch 2.0 | Reconstruction error as anomaly signal — detects gradual temporal drift |
| XGBoost Classifier | XGBoost 1.7 | Fault type classification across 9 fault classes |

## Why Three Models

Each model catches a different failure signature:

- **Isolation Forest** — scores the combination of all sensor values at a single point in time. Fast O(log n) inference, no distributional assumptions, ideal for real-time streaming.
- **LSTM Autoencoder** — processes sequences of readings over time. High reconstruction error signals that the recent trend has broken the learned normal behaviour — catches gradual drift that looks normal at any individual reading.
- **XGBoost Classifier** — once an anomaly is confirmed by the two unsupervised models, classifies the fault type using labelled historical data. Produces feature importance scores that explain which sensors drove the classification.

A reading must breach both Isolation Forest and LSTM thresholds to trigger a workflow, significantly reducing false positives compared to either model alone.

## Training

All three models are trained via the SageMaker Pipeline (`src/training/pipeline.py`), which runs three parallel training jobs against synthetic sensor data generated by `src/data/generate_training_data.py` (~960k rows, 6 months × 12 tanks).

Training scripts:
- `src/training/isolation_forest/`
- `src/training/lstm_autoencoder/`
- `src/training/xgboost_classifier/`
